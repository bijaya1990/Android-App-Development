PikaCart logo pack
==================
Font: Poppins (Google Fonts, SIL Open Font License, free for commercial use).
Text is converted to vector outlines, so the SVGs need no font installed.

Colours
  Indigo   #5B4BFF  (primary / "Cart")
  Violet   #8B5CF6  (badge gradient start)
  Deep     #3F2BE0  (badge gradient end)
  Yellow   #FFC83D -> #FF9F1C  (lightning bolt)
  Ink      #16161D  ("Pika" on light backgrounds)

Files
  png/pikacart-logo.png            Website header logo (light background)
  png/pikacart-logo-white.png      For dark backgrounds / dark mode
  png/pikacart-logo-tagline*.png   With "DIGITAL MARKETPLACE" line
  png/pikacart-logo-stacked*.png   Square-ish, for social media / banners
  favicon/pikacart-icon-512.png    WordPress Site Icon (favicon + app icon)
  favicon/*                        Other icon sizes, favicon.ico
  svg/*                            Vector originals (print, any size)

WordPress
  Appearance -> Customize -> Site Identity
    Logo       : png/pikacart-logo.png
    Site Icon  : favicon/pikacart-icon-512.png
