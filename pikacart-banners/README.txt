PikaCart demo banners
=====================

Upload these from Admin -> Banners after the new build (or use them as
Canva/Figma starting points and replace the text).

hero-cards-1000x500/   Top carousel cards (2:1). One image for desktop + mobile.
  hero-1-dussehra-sale        -> link to /sale/ or /?coupon=DUSSEHRA30
  hero-2-school-website       -> link to the School Website service
  hero-3-resume-templates     -> link to Resume category
  hero-4-study-notes          -> link to Study Notes category
  hero-5-puja-committee       -> link to Puja Committee Website service
  hero-6-kids-zone            -> link to Kids Zone category

offer-tiles-600x600/   Square tile photos. Type the label and caption in admin:
  tile-resume              label "From ₹49"         caption "Resume templates"
  tile-notes               label "From ₹29"         caption "Class 12 notes"
  tile-kids                label "From ₹29"         caption "Kids worksheets"
  tile-school-website      label "Starting ₹5,000"  caption "School websites"
  tile-committee-website   label "Starting ₹3,000"  caption "Committee websites"
  tile-canva-packs         label "From ₹49"         caption "Canva post packs"

campaign/              Wide festival banner: desktop 1460x325 + mobile 1080x540.
cart-strip-1200x150/   Thin offer strip above cart totals (first-order code PIKA10).
preview/               How it all looks on the homepage (desktop + mobile).

Before going live: create the coupons DUSSEHRA30 and PIKA10 in
Admin -> Coupons (or edit the banners) so the codes shown actually work,
and schedule the Dussehra banners to your real sale dates.
