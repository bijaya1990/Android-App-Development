# Saapwaa's Narak Vlogs — 400 Video Prompts

40 episodes × 10 scenes. Each prompt is one ready-to-generate 10-second, 9:16 comedy vlog clip with Hindi dialogue built in, and every prompt is under 900 characters.

- `dist/saapwaa-narak-400-prompts.pdf` — the prompt book
- `dist/saapwaa-narak-400-prompts.txt` — the same prompts as plain text (best for copy and paste)
- `scenes/*.txt` — scene source; `tools/make.py` assembles and checks the prompts and builds the PDF (`python3 tools/make.py`)
